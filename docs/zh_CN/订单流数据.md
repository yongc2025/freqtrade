# 订单流数据

本指南介绍如何在 Freqtrade 中利用公共成交数据进行高级订单流分析。

!!! warning "实验性功能"
    订单流功能目前为 beta 版，未来可能变动。如有问题或建议请在 [Freqtrade GitHub](https://github.com/freqtrade/freqtrade/issues) 反馈。
    目前未与 freqAI 联动测试，二者结合暂不在官方支持范围内。

!!! warning "性能提示"
    订单流分析需用到原始成交数据，数据量大，首次启动时需下载大量历史成交，可能导致启动变慢且内存占用增加。请确保有足够资源。

## 快速开始

### 启用公共成交数据

在 `config.json` 的 `exchange` 部分添加：

```json
"exchange": {
   ...
   "use_public_trades": true,
}
```

### 配置订单流参数

在 config.json 的 orderflow 部分设置：

- `cache_size`：缓存多少根订单流K线，减少重复计算
- `max_candles`：最多获取多少根K线的成交数据
- `scale`：足迹图的价格分箱大小
- `stacked_imbalance_range`：连续失衡价位的最小数量
- `imbalance_volume`：过滤成交量低于该值的失衡
- `imbalance_ratio`：过滤失衡比低于该值的情况

```json
"orderflow": {
    "cache_size": 1000, 
    "max_candles": 1500, 
    "scale": 0.5, 
    "stacked_imbalance_range": 3, // 至少连续多少个失衡
    "imbalance_volume": 1, // 过滤成交量低于该值
    "imbalance_ratio": 3 // 过滤比值低于该值
  },
```

## 下载回测用成交数据

用 --dl-trades 参数下载历史成交数据：

```bash
freqtrade download-data -p BTC/USDT:USDT --timerange 20230101- --trading-mode futures --timeframes 5m --dl-trades
```

!!! warning "数据可用性"
    并非所有交易所都提供公共成交数据。支持的交易所若无数据会有警告。
