# Freqtrade 量化交易战略方案 (2026版)

本方案由 GitHub Copilot 专家组针对不同市场周期与交易需求深度定制，旨在通过多策略组合实现资产的稳健增值与高波动套利。

---

## 策略一：现货长线定投策略 ——【宏观守望者 (Macro-Guardian)】

### 1.1 设计目标

针对 BTC、ETH 等市值前五的高价值资产，寻找大周期的价值洼地，执行“技术型定投”，避免在高位盲目买入。

### 1.2 核心逻辑

- **资产范围**：BTC/USDT, ETH/USDT, SOL/USDT, BNB/USDT。
- **交易模式**：Spot (现货)。
- **入场算法**：
  - **周期**：4h 或 1d 级别。
  - **条件**：价格跌破 **Bollinger Bands 下轨**（stds=2.0）且 **RSI < 30**。
  - **过滤**：价格必须明显偏离 **EMA200**（均线回归逻辑）。
- **离场算法**：
  - 不设硬性止损。
  - 当 RSI > 70 或价格触及布林带上轨时，执行分批止盈（ROI 设置 > 30%）。

## 策略二：合约中长线多空策略 ——【稳定性大师 (Stability-Master)】

### 2.1 设计目标

针对主流币合约，捕捉确定性较强的中线趋势，利用杠杆放大收益，同时通过均线过滤杂波。

### 2.2 核心逻辑

- **资产范围**：BTC, ETH, 及市值前 10 的主流合约。
- **交易模式**：Futures (期货)，杠杆 1x - 3x。
- **技术栈**：EMA200, MACD, ADX, Bollinger Width。
- **执行逻辑**：
  - **做多 (Long)**：`ADX > 25` (有趋势) + `MACD 金叉` + `价格 > EMA200`。
  - **做空 (Short)**：`ADX > 25` + `MACD 死叉` + `价格 < EMA200`。
- **风控管理**：
  - **波动过滤**：检查 `bb_width`，若市场处于横盘缩量期（开口过窄）则不交易。
  - **止损**：动态追踪止损 (Trailing Stoploss)，初始止损 3%-5%。

## 策略三：合约短线狙击策略 ——【波动猎手 (Volatility-Sniper)】

### 3.1 设计目标

针对高成交量、高波动的山寨币（Altcoins），捕捉极端情绪下的瞬间超买超卖，进行高频次套利。

### 3.2 核心逻辑

- **资产范围**：成交量 Top 20 的高波动品种（如 PEPE, WIF, SOL 等）。
- **交易模式**：Futures (期货)，杠杆 1x (根据波动率调整)。
- **技术栈**：MFI (资金流), RSI, Volume Mean, Bollinger Bands (stds=2.5)。
- **执行逻辑**：
  - **做多 (抄底)**：`MFI < 20` (资金衰竭) + `RSI < 25` + 价格瞬间击穿布林带超跌轨。
  - **做空 (摸顶)**：`Volume > 3.0 * Volume_Mean` (放量反抽) + `RSI > 80` + 价格偏离布林上轨。
- **风控管理**：
  - **快进快出**：ROI 设置极其紧凑（1%-2% 即刻撤离）。
  - **硬性止损**：严防山寨币单边行情，止损不得超过 2%。
