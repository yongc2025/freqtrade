# 项目简介

Freqtrade 是一个用 Python 编写的免费开源数字货币量化交易机器人，支持主流交易所，可通过 Telegram 或 WebUI 控制。内置回测、绘图、资金管理工具，并支持基于机器学习的策略优化。

!!! danger "免责声明"
	本软件仅供学习交流，请勿投入无法承受损失的资金。使用风险自负，作者及相关方不对任何交易结果负责。

	强烈建议先用 Dry-run（模拟盘）模式熟悉机器人，充分理解其工作原理和盈亏预期后再实盘。

	建议具备基础编程和 Python 知识，欢迎阅读源码，理解其算法和实现机制。

![freqtrade 截图](../assets/freqtrade-screenshot.png)

## 功能特性

- 策略开发：用 Python（pandas）编写交易策略，官方[策略仓库](https://github.com/freqtrade/freqtrade-strategies)有丰富示例。
- 市场数据下载：下载目标交易所和币对的历史行情数据。
- 回测：用历史数据检验策略表现。
- 优化：通过超参数优化（机器学习）寻找最佳策略参数，包括买入、卖出、止盈、止损等。
- 市场选择：可用静态币对列表，或基于成交量/价格自动筛选（回测时仅支持静态列表），也可黑名单过滤。
- 运行：支持 Dry-Run（模拟盘）和 Live-Trade（实盘）两种模式。
- 控制/监控：通过 Telegram 或 WebUI 启停机器人、查看盈亏、每日总结、持仓等。
- 分析：支持对回测结果或交易历史（SQL数据库）进一步分析、自动绘图，或导入[交互式分析环境](data-analysis.md)。

## 环境要求

### 硬件要求

建议使用 Linux 云服务器，最低配置：

- 2GB 内存
- 1GB 硬盘空间
- 2核 CPU

### 软件要求

- Docker（推荐）

或

- Python 3.11+
- pip (pip3)
- git
- TA-Lib
- virtualenv（推荐）
