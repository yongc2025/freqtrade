# 杠杆交易

!!! Note "同一个账户运行多个机器人"
    您不能在同一个杠杆账户上运行两个机器人。对于杠杆/保证金交易，Freqtrade 假设它是账户的唯一使用者，并基于此假设计算所有的爆仓价（平仓线）。

!!! Danger "杠杆交易风险极高"
    在使用现货市场实盘运行且未显示正收益的策略之前，请勿使用大于 1 的杠杆。检查策略的止损。如果杠杆为 2，止损设为 0.5 (50%) 就太低了，这些交易在达到该止损位之前就会被爆仓。
    对于因使用本软件或此模式而产生的任何损失，我们不承担任何责任。

    请仅在您了解 Freqtrade（以及您的策略）的工作原理时才使用高级交易模式。
    此外，永远不要拿超过您承受能力的资金去冒险。

如果您已经有一个现有策略，请阅读[策略迁移指南](策略迁移指南.md#v2-与-v3-之间的策略迁移)将您的策略从 Freqtrade v2 策略迁移到可以进行做空和期货交易的 v3 版本策略。

## 做空 (Shorting)

当交易模式 (`trading_mode`) 设置为 `spot`（现货）时，无法进行做空。要进行做空交易，`trading_mode` 必须设置为 `margin`（目前暂不可用）或 [`futures`](#期货-futures)，并将 [`margin_mode`](#保证金模式-margin-mode) 设置为 [`cross`](#全仓保证金模式-cross-margin-mode)（全仓）或 [`isolated`](#逐仓保证金模式-isolated-margin-mode)（逐仓）。

对于要进行做空的策略，策略类必须设置类变量 `can_short = True`。

请阅读[策略自定义](策略自定义.md#进场信号规则)了解如何设置进入和退出做空交易的信号。

## 理解 `trading_mode`（交易模式）

可选值为：`spot`（默认，现货）、`margin`（*目前暂不可用*，保证金）或 `futures`（期货）。

### 现货 (Spot)

常规交易模式（低风险）

- 仅限做多交易（无做空）。
- 无杠杆。
- 无爆仓。
- 获得的利润/损失等于资产价值的变化（减去交易手续费）。

### 杠杆交易模式

通过杠杆，交易者从交易所借入资金。资金必须全额偿还给交易所（可能带有利息），交易者保留使用借入资金进行的任何交易的利润，或支付任何损失。

因为资金必须始终偿还，当杠杆账户中的资产总值下降到某一点时（此时亏损总额小于交易者在杠杆账户中实际拥有的抵押品价值），交易所将对使用借入资金进行的交易进行**强制平仓**（爆仓，Liquidation，即强行出售交易者的资产），以确保交易者有足够的资金将借入的资产归还给交易所。交易所还会收取**爆仓费** (liquidation fee)，增加交易者的损失。

由于这个原因，**如果您不清楚自己在做什么，请不要进行杠杆交易。杠杆交易具有高风险，可能导致您的资产价值迅速降至 0，且没有再次增值的机会。**

#### 保证金 (Margin)（目前暂不可用）

交易发生在现货市场，但交易所借给您的货币金额等于所选的杠杆倍数。您将借给您的金额连同利息偿还给交易所，您的利润/损失将乘以指定的杠杆倍数。

#### 期货 (Futures)

永续合约（也称为合约期货，Perpetual Futures）是以与其所基于的基础资产价格紧密挂钩的价格进行交易的合同。您不是在交易实际资产，而是在交易衍生品合约。与定期期货或期权合约相比，永续合约可以无限期持续。

除了由于期货合约价格变化产生的收益/损失外，交易者还交换“资金费率” (funding fees)，其收益/损失金额源于期货合约与基础资产之间的价格差异。期货合约与基础资产之间的价格差异因交易所而异。

要在期货市场进行交易，您需要将 `trading_mode` 设置为 "futures"。
您还需要选择“保证金模式”（说明如下）。

``` json
"trading_mode": "futures",
"margin_mode": "isolated"
```

##### 交易对命名

Freqtrade 遵循 [CCXT 期货命名约定](https://docs.ccxt.com/#/README?id=perpetual-swap-perpetual-future)。
因此，期货交易对的命名格式为 `基础货币/计价货币:结算货币`（例如 `ETH/USDT:USDT`）。

### 保证金模式 (Margin mode)

除了 `trading_mode` 外，您还需要配置 `margin_mode`。
虽然 Freqtrade 目前仅支持一种保证金模式，但这将会改变，通过现在的配置，您可以为将来的更新做好准备。

可选值为：`isolated`（逐仓）或 `cross`（全仓）。

#### 逐仓保证金模式 (Isolated margin mode)

每个市场（交易对）在单独的账户中保存抵押品。

``` json
"margin_mode": "isolated"
```

#### 全仓保证金模式 (Cross margin mode)

一个账户用于在多个市场（交易对）之间共享抵押品。必要时从总账户余额中提取保证金以避免爆仓。

``` json
"margin_mode": "cross"
```

请阅读[交易所特定说明](交易所.md)以了解支持此模式的交易所及其差异。

!!! Warning "爆仓风险增加"
    全仓保证金模式增加了整个账户爆仓的风险，因为所有交易共享相同的抵押品。
    一笔交易的亏损可能会影响其他交易的爆仓价格。
    此外，全仓仓位的影响可能无法在模拟交易 (dry-run) 或回测模式中完全模拟。

## 设置要使用的杠杆

不同的策略和风险状况需要不同级别的杠杆。
虽然您可以配置一个静态杠杆值，但 Freqtrade 提供了通过[策略杠杆回调函数](策略回调函数.md#leverage-callback)进行调整的灵活性——这允许您按交易对设置不同的杠杆，或基于对策略结果有利的其他因素。

如果未实现，杠杆默认为 1x（无杠杆）。

!!! Warning
    更高的杠杆也意味着更高的风险——请务必充分理解使用杠杆的影响！

## 理解 `liquidation_buffer`（爆仓缓冲）

*默认值为 `0.05`*

指定在爆仓价和止损价之间设置多大的安全网比例，以防止仓位达到爆仓价。
这个人工爆仓价计算如下：

`freqtrade_liquidation_price = liquidation_price ± (abs(open_rate - liquidation_price) * liquidation_buffer)`

- `±` = 做多交易为 `+`
- `±` = 做空交易为 `-`

可选值为 0.0 到 0.99 之间的任何浮点数。

**例：** 如果以 10 coin/USDT 的价格进场，且该交易的爆仓价为 8 coin/USDT，则在 `liquidation_buffer` 设置为 `0.05` 的情况下，该交易的最小止损位将为 $8 + ((10 - 8) \times 0.05) = 8 + 0.1 = 8.1$。

!!! Danger "`liquidation_buffer` 为 0.0 或较低的值很可能导致爆仓和产生爆仓费"
    目前 Freqtrade 能够计算爆仓价，但不会计算爆仓费。将 `liquidation_buffer` 设置为 0.0 或使用较低的值可能会导致您的仓位被爆仓。由于 Freqtrade 不跟踪爆仓费，因此爆仓将导致机器人的利润/损失结果不准确。如果您使用较低的 `liquidation_buffer`，建议在您的交易所支持的情况下使用 `stoploss_on_exchange`（交易所端止损）。

## 缺失的资金费率 (Funding rates)

对于期货数据，交易所通常提供期货 K 线、标记价格和资金费率。然而，通常会出现虽然可以获得 K 线和标记价格，但无法获得资金费率的情况。这可能会影响回测时间范围，即您可能只能测试最近的时间范围，而不能测试更早的时间范围，从而遇到 `No data found. Terminating.` 报错。要解决此问题，请添加 [配置文件说明](配置文件说明.md) 中列出的 `futures_funding_rate` 配置选项，建议将其设置为 `0`，除非您知道特定交易对、交易所和时间范围的特定资金费率。将其设置为非 `0` 的任何值都可能对策略内的利润计算产生剧烈影响，例如在 `custom_exit`、`custom_stoploss` 等函数中。

!!! Warning "这将意味着您的回测是不准确的。"
    这不会覆盖交易所可用的真实资金费率，但请记住，设置错误的资金费率意味着在无法获得真实资金费率的历史时间范围内，回测结果将是不准确的。

### 开发者相关

#### 保证金模式 (Margin mode)

对于做空，用于支付“借入”货币利息的货币是在平仓交易的同时购买的（这意味着做空平仓交易中购买的数量大于做空开仓交易中出售的数量）。

对于做多，用于支付“借入”利息的货币已由用户拥有，不需要购买。利息从交易的 `close_value`（平仓价值）中扣除。

所有费用都包含在交易过程中的 `current_profit`（当前利润）计算中。

#### 期货模式 (Futures mode)

资金费率将从交易总额中加算或减去。
