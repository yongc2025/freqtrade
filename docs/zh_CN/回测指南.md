# 回测指南

本页介绍如何用回测功能验证你的策略表现。

回测需要有历史数据。如何获取目标交易所和币对的数据，请参见《数据下载.md》。

回测也可在 [Web 界面](freq-ui.md#backtesting)中进行。

## 用回测测试你的策略

当你有了买入/卖出策略和历史数据后，可以用回测功能检验其在真实历史行情下的表现。

回测会用配置文件中的币对，从 `user_data/data/<exchange>` 目录加载历史K线（OHLCV）数据。
如无数据，会提示先用 `freqtrade download-data` 下载。详情见《数据下载.md》。

回测结果可帮助你判断策略长期盈利概率。

所有利润计算都包含手续费，freqtrade 会用交易所默认手续费。

!!! 警告 "回测用动态币对列表"
回测支持动态币对列表（部分类型），但其结果依赖当前市场状态，无法还原历史币对池，结果不可复现。
建议用 [`test-pairlist`](utils.md#test-pairlist) 生成静态币对列表，保证回测结果可复现。

!!! 注意
回测结果默认导出到 `user_data/backtest_results`，可用于进一步分析或用 `freqtrade plot-dataframe` 绘图。

### 启动资金

回测需指定初始资金，可用 `--dry-run-wallet <金额>`、`--starting-balance <金额>` 或配置项 `dry_run_wallet` 设置。
该金额必须大于 `stake_amount`，否则无法模拟交易。

### 动态仓位

回测支持[动态仓位](configuration.md#dynamic-stake-amount)，即 `stake_amount` 设为 "unlimited"，初始资金会按 `max_open_trades` 平均分配，盈利会复利。

### 回测命令示例

5分钟K线：

```bash
freqtrade backtesting --strategy AwesomeStrategy
```

1分钟K线：

```bash
freqtrade backtesting --strategy AwesomeStrategy --timeframe 1m
```

自定义初始资金：

```bash
freqtrade backtesting --strategy AwesomeStrategy --dry-run-wallet 1000
```

指定历史数据目录：

```bash
freqtrade backtesting --strategy AwesomeStrategy --datadir user_data/data/binance-20180101
```

多策略对比：

```bash
freqtrade backtesting --strategy-list SampleStrategy1 AwesomeStrategy --timeframe 5m
```

不导出交易：

```bash
freqtrade backtesting --strategy backtesting --export none --config config.json
```

自定义导出目录：

```bash
freqtrade backtesting --strategy backtesting --export trades --backtest-directory=user_data/custom-backtest-results
```

更多请参见[策略启动期](strategy-customization.md#strategy-startup-period)。

### 自定义手续费

如需模拟手续费折扣，可用 `--fee` 指定，单位为比率（如0.001表示0.1%）：

```bash
freqtrade backtesting --fee 0.001
```

!!! 注意
默认会用交易所手续费，仅需实验时指定。

### 时间区间

用 `--timerange` 控制回测区间：

- 用到 2018/01/31：`--timerange=-20180131`
- 从 2018/01/31 起：`--timerange=20180131-`
- 2018/01/31 到 2018/03/01：`--timerange=20180131-20180301`
- 用时间戳：`--timerange=1527595200-1527618600`
