# Freqtrade 产品介绍

## 1. 什么是 Freqtrade？
Freqtrade 是一款基于 Python 的自由开源加密货币套利与机器学习交易机器人。它旨在支持所有主流交易所，并可以通过 Telegram 或 WebUI 进行控制。它包含了回测、绘图和资产管理工具，以及通过机器学习进行的策略优化（FreqAI）。

## 2. 核心架构与优势
*   **全自动化交易**：支持 7x24 小时自动买入、卖出及头寸管理。
*   **机器学习集成 (FreqAI)**：内置强大的机器学习框架，支持 LightGBM、XGBoost、Catboost 等模型，实现自适应市场变化的预测。
*   **严谨的回测系统**：支持历史数据仿真，帮助验证策略在过去市场表现中的盈利能力。
*   **多交易所支持**：支持超过 80 家主流交易所（如 Bybit, Binance, OKX, Gate.io, KuCoin 等）。
*   **极高灵活性**：策略完全由 Python 编写，支持复杂逻辑、多种技术指标及自定义回调。
*   **全方位监控**：支持 Telegram 机器人指令查阅状态、WebUI 可视化监控。

## 3. 核心功能模块
*   **Backtesting (回测)**：在历史数据上测试你的交易想法。
*   **Hyperopt (超参数优化)**：使用信号处理领域的方法（如贝叶斯优化）为策略寻找最优的参数组合（如指标周期、停止损点等）。
*   **FreqAI (智能预测)**：通过滑窗学习模式，不断重训模型以捕捉最新的市场效率。
*   **Edge (边缘计算)**：自动分析每个币种的获胜概率和风险回报比，动态调整仓位。
*   **Plotting (绘图)**：将交易信号、指标和盈利曲线可视化。

## 4. 适用人群
*   **量化交易者**：需要一个稳定、可扩展的交易框架。
*   **Python 开发者**：希望通过编写代码实现自动化资产管理。
*   **机器学习爱好者**：希望将预测模型应用于金融实战。
*   **职业交易员**：需要工具辅助执行策略、排除情绪干扰并进行大规模数据验证。

## 5. 资源配置要求
根据您使用的功能不同，对硬件的需求也有所区别：

| 资源 | 基础交易 (不含AI) | 策略优化 (Hyperopt) | FreqAI (机器学习) |
| :--- | :--- | :--- | :--- |
| **CPU** | 1-2 核 (如树莓派) | 越多越好 (全核心占用) | 4-8 核以上 (建议) |
| **内存 (RAM)** | 2GB+ | 4GB - 8GB+ | 8GB - 16GB+ |
| **磁盘空间** | < 1GB | 1GB - 5GB+ | 10GB - 50GB+ (存放模型) |
| **网络** | 稳定宽带 | 无要求 (离线查询) | 稳定宽带 |

## 6. 功能与资源对应说明
*   **轻量化运行**：如果您只运行基于简单逻辑（如 EMA 交叉）的机器人，甚至可以在最低配置的 VPS 上运行。
*   **大数据回测**：深度回测需要较大的内存来加载历史 K 线。如果内存不足，建议缩小 `--timerange`。
*   **FreqAI 专用环境**：由于机器学习模型和特征数据常驻内存，且重训极其消耗 CPU，建议在独立的服务器或高性能 PC 上运行。
