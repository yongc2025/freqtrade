# 启动机器人

本页介绍了机器人的不同参数以及如何运行它。

!!! Note "注意"
    如果您使用了 `setup.sh`，在运行 freqtrade 命令之前，请不要忘记激活您的虚拟环境 (`source .venv/bin/activate`)。

!!! Warning "时钟同步"
    运行机器人的系统时钟必须准确，且必须足够频繁地与 NTP 服务器同步，以避免与交易所通信时出现问题。

### 如何指定使用哪个配置文件？

机器人允许您通过 `-c/--config` 命令行选项选择要使用的配置文件：

```bash
freqtrade trade -c path/far/far/away/config.json
```

默认情况下，机器人从当前工作目录加载 `config.json` 配置文件。

### 如何使用多个配置文件？

机器人允许您通过在命令行中指定多个 `-c/--config` 选项来使用多个配置文件。在后面的配置文件中定义的配置参数将覆盖在前面指定的配置文件中定义的同名参数。

例如，您可以为用于交易的交易所创建一个包含密钥（key）和密钥（secret）的单独配置文件，并在干跑模式（实际上不需要它们）下运行时指定带有空密钥和密钥值的默认配置文件：

```bash
freqtrade trade -c ./config.json
```

并在正常的实盘交易模式下运行时同时指定两个配置文件：

```bash
freqtrade trade -c ./config.json -c path/to/secrets/keys.config.json
```

通过为包含实际机密的文件设置适当的文件权限，这可以帮助您在本地机器上隐藏私有的交易所密钥，此外，还可以防止在项目 Issue 或互联网上发布配置示例时意外泄露敏感的私人数据。

有关此技术的更多详细信息和示例，请参阅 [配置文件说明](配置文件说明.md) 文档页面。

### 用户数据存储在哪里

Freqtrade 允许使用 `freqtrade create-userdir --userdir someDirectory` 创建用户数据目录。
该目录的结构如下：

```
user_data/
├── backtest_results
├── data
├── hyperopts
├── hyperopt_results
├── plot
└── strategies
```

您可以在配置中添加 "user_data_dir" 设置，以便始终将机器人指向此目录。
或者，在每个命令中传入 `--userdir`。
如果目录不存在，机器人将无法启动，但会自动创建必要的子目录。

该目录应包含您的自定义策略、自定义超参数优化（hyperopts）和超参数优化损失函数、回测历史数据（使用回测命令或下载脚本下载）以及图表输出。

建议使用版本控制（如 Git）来跟踪策略的更改。

### 如何使用 **--strategy**？

此参数允许您加载自定义策略类。
要测试机器人安装，您可以使用通过 `create-userdir` 子命令安装的 `SampleStrategy`（通常在 `user_data/strategy/sample_strategy.py`）。

机器人将在 `user_data/strategies` 中搜索您的策略文件。
要使用其他目录，请阅读下一节关于 `--strategy-path` 的内容。

要加载策略，只需在此参数中传入类名（例如：`CustomStrategy`）。

**示例：**
在 `user_data/strategies` 中，您有一个文件 `my_awesome_strategy.py`，其中包含一个名为 `AwesomeStrategy` 的策略类。加载它的命令为：

```bash
freqtrade trade --strategy AwesomeStrategy
```

如果机器人找不到您的策略文件，它将在错误消息中显示原因（文件未找到或代码中有错误）。

在 [策略自定义](策略自定义.md) 中了解有关策略文件的更多信息。

### 如何使用 **--strategy-path**？

此参数允许您添加额外的策略查找路径，该路径将在默认位置之前被检查（传递的路径必须是目录！）：

```bash
freqtrade trade --strategy AwesomeStrategy --strategy-path /some/directory
```

#### 如何安装策略？

这非常简单。将您的策略文件复制粘贴到 `user_data/strategies` 目录中或使用 `--strategy-path`。大功告成，机器人即可准备使用。

### 如何使用 **--db-url**？

当您在干跑模式下运行机器人时，默认情况下不会在数据库中存储任何交易。如果您想使用 `--db-url` 将机器人操作存储在数据库中，请在生产模式中使用它来指定自定义数据库。示例命令：

```bash
freqtrade trade -c config.json --db-url sqlite:///tradesv3.dry_run.sqlite
```
