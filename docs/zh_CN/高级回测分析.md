# 高级回测分析

## 分析买入/开仓与卖出/平仓标签

理解策略在不同买入/开仓标签下的行为有助于优化策略。你可能希望获得比默认回测输出更复杂的每个买入/卖出条件的统计信息，也可能想分析导致开仓信号的K线指标值。

!!! 注意
    下述买入原因分析仅适用于回测，不适用于超参数优化（hyperopt）。

需用 `--export signals` 选项运行回测，导出信号和交易数据：

```bash
freqtrade backtesting -c <config.json> --timeframe <tf> --strategy <strategy_name> --timerange=<timerange> --export=signals
```

此命令会让 freqtrade 输出包含策略、币对及对应 DataFrame（产生开仓/平仓信号的K线）的 pickle 字典。
若策略开仓次数较多，该文件可能很大，请定期清理 `user_data/backtest_results` 目录下的旧导出文件。

每次回测前，建议删除旧回测结果，或用 `--cache none` 选项，避免使用缓存。

执行后你会在 `user_data/backtest_results` 目录下看到 `backtest-result-{timestamp}_signals.pkl` 和 `backtest-result-{timestamp}_exited.pkl` 文件。

要分析开仓/平仓标签，需用 `freqtrade backtesting-analysis` 命令，并用 `--analysis-groups` 指定分组方式（空格分隔）：

```bash
freqtrade backtesting-analysis -c <config.json> --analysis-groups 0 1 2 3 4 5
```

该命令会读取最近的回测结果。`--analysis-groups` 用于指定不同分组方式，输出每组或每笔交易的收益统计：

* 0：按 enter_tag 汇总整体胜率和收益
* 1：按 enter_tag 汇总收益
* 2：按 enter_tag 和 exit_tag 汇总收益
* 3：按币对和 enter_tag 汇总收益
* 4：按币对、enter_tag 和 exit_tag 汇总（数据量大）
* 5：按 exit_tag 汇总收益

更多选项可用 `-h` 查看。

### 使用 backtest-filename

默认情况下，`backtesting-analysis` 处理 `user_data/backtest_results` 目录下最新回测结果。
如需分析历史回测结果，可用 `--backtest-filename` 指定目标文件，便于随时复盘历史回测输出：

```bash
freqtrade backtesting -c <config.json> --strategy <strategy_name> --timerange <timerange> --export signals --backtest-filename backtest-result-2025-03-05_20-38-34.zip
```

日志中会输出导出文件的时间戳和文件名。
