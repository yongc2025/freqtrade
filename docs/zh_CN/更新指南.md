# 如何更新 (How to update)

要更新您的 freqtrade 安装，请根据您的安装方法使用以下方法之一。

!!! Note "追踪变更"
    重大变更/行为变更将记录在随每个版本发布的变更日志 (Changelog) 中。
    对于 `develop` 分支，请关注 PR 动态，以免对变更感到意外。

## 为什么要更新？

保持机器人更新不仅能确保您拥有最新的功能和改进，也是保持机器人平稳运行的需求。
Freqtrade 严重依赖于底层的交易所 API，而各个交易所的 API 变更相当频繁。
为了确保持续的兼容性，请务必定期更新您的机器人。

## Docker

!!! Note "使用 `master` 镜像的旧版安装"
    我们将发布版镜像从 `master` 切换为 `stable` —— 请调整您的 `docker-compose` 文件，并将 `freqtradeorg/freqtrade:master` 替换为 `freqtradeorg/freqtrade:stable`。

``` bash
docker compose pull
docker compose up -d
```

## 通过安装脚本安装

``` bash
./setup.sh --update
```

!!! Note "注意"
    请确保在禁用虚拟环境的情况下运行此命令！

## 普通原生安装 (Plain native installation)

请确保您也更新了依赖项 —— 否则某些功能可能会在您未察觉的情况下损坏。

``` bash
git pull
pip install -U -r requirements.txt
pip install -e .

# 确保 freqUI 是最新版本
freqtrade install-ui 
```

## 更新中的问题

更新问题通常源于缺失依赖项（您没有遵循上述指令）或依赖项安装失败。
我们尽量确保主要平台都有大型依赖项的轮子 (wheels) 可用，但有时这并不可行。

请参阅相应的安装章节（下面链接了常见问题部分）。
