# 高级安装后配置

本页介绍机器人安装后可用的一些高级任务和配置选项，适用于有特殊需求的环境。

如果你不了解本页内容，通常无需使用这些功能。

## 运行多个 Freqtrade 实例

本节介绍如何在同一台机器上同时运行多个机器人。

### 注意事项

* 每个实例需使用不同的数据库文件。
* 每个实例需使用不同的 Telegram 机器人（需多份配置文件，仅启用 Telegram 时适用）。
* 每个实例需使用不同端口（仅启用 REST API 时适用）。

### 不同数据库文件

Freqtrade 用 SQLite 数据库存储历史交易、当前持仓等信息。默认情况下，实盘和 Dry-run（模拟盘）会用不同数据库（未指定 database-url 时）：
- 实盘：`tradesv3.sqlite`
- Dry-run：`tradesv3.dryrun.sqlite`

可用 `--db-url` 参数指定数据库路径。例如：

```bash
freqtrade trade -c MyConfig.json -s MyStrategy
# 等价于
freqtrade trade -c MyConfig.json -s MyStrategy --db-url sqlite:///tradesv3.dryrun.sqlite

### Docker 多实例

用 docker-compose 可配置多实例，示例：

```yml
version: '3'
services:
  freqtrade1:
    image: freqtradeorg/freqtrade:stable
    restart: always
    container_name: freqtrade1
    volumes:
      - "./user_data:/freqtrade/user_data"
    ports:
     - "127.0.0.1:8080:8080"
    command: >
      trade
      --logfile /freqtrade/user_data/logs/freqtrade1.log
      --db-url sqlite:////freqtrade/user_data/tradesv3_freqtrade1.sqlite
      --config /freqtrade/user_data/config.json
      --config /freqtrade/user_data/config.freqtrade1.json
      --strategy SampleStrategy
  freqtrade2:
    image: freqtradeorg/freqtrade:stable
    restart: always
    container_name: freqtrade2
    volumes:
      - "./user_data:/freqtrade/user_data"
    ports:
      - "127.0.0.1:8081:8080"
    command: >
      trade
      --logfile /freqtrade/user_data/logs/freqtrade2.log
      --db-url sqlite:////freqtrade/user_data/tradesv3_freqtrade2.sqlite
      --config /freqtrade/user_data/config.json
      --config /freqtrade/user_data/config.freqtrade2.json
      --strategy SampleStrategy
```

服务名 freqtrade1/2 可自定义。每个实例需用不同数据库、端口和 Telegram 配置。

## 使用其他数据库系统

Freqtrade 基于 SQLAlchemy，支持多种数据库。需自行安装相应驱动，详见 [SQLAlchemy 文档](https://docs.sqlalchemy.org/en/14/core/engines.html#database-urls)。

已验证可用：
- sqlite（默认）
- PostgreSQL
- MariaDB

!!! warning
    使用下列数据库需自行负责管理，官方不提供安装、维护、备份等支持。

### PostgreSQL

安装：
`pip install "psycopg[binary]"`

用法：
`... --db-url postgresql+psycopg://<用户名>:<密码>@localhost:5432/<数据库>`

多实例建议用不同数据库或不同用户/schema。

### MariaDB / MySQL

安装：
`pip install pymysql`

用法：
`... --db-url mysql+pymysql://<用户名>:<密码>@localhost:3306/<数据库>`

## 配置 systemd 服务

将 `freqtrade.service` 复制到 `~/.config/systemd/user`，并修改 `WorkingDirectory` 和 `ExecStart`。

!!! note
    某些系统（如 Raspbian）需放到 `/etc/systemd/user/`（需 root 权限）。

启动服务：
```bash
systemctl --user start freqtrade
```

如需断开登录后仍运行，需启用 linger：
```bash
sudo loginctl enable-linger "$USER"
```

如用 systemd 管理，可用 watchdog 监控机器人状态并自动重启。配置 `internals.sd_notify` 或 `--sd-notify` 后，机器人会向 systemd 发送状态。

`freqtrade.service.watchdog` 为 systemd watchdog 配置示例。

!!! note
    sd_notify 与 systemd 通信在 Docker 容器内无效。

## 高级日志配置

Freqtrade 默认用 Python logging 模块。可通过配置文件自定义日志格式、输出方式。

默认配置如下，文件日志需取消注释 filename 并指定路径：

```json
{
  "log_config": {
      "version": 1,
      "formatters": {
          "basic": {
              "format": "%(message)s"
          },
          "standard": {
              "format": "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
          }
      },
      "handlers": {
          "console": {
              "class": "freqtrade.loggers.ft_rich_handler.FtRichHandler",
              "formatter": "basic"
          },
          "file": {
              "class": "logging.handlers.RotatingFileHandler",
              "formatter": "standard",
              // "filename": "someRandomLogFile.log",
              "maxBytes": 10485760,
              "backupCount": 10
          }
      },
      "root": {
          "handlers": [
              "console",
              // "file"
          ],
          "level": "INFO",
      }
  }
}
```

!!! tip "分离日志配置"
    建议将日志配置单独成文件，通过[多配置文件功能](configuration.md#multiple-configuration-files)引入，避免重复。

---

### 日志输出到 syslog

可通过 log_config 配置日志输出到本地或远程 syslog：

```json
{
  // ...
  "log_config": {
    "version": 1,
    "formatters": {
      "syslog_fmt": {
        "format": "%(name)s - %(levelname)s - %(message)s"
      }
    },
    "handlers": {
      "syslog": {
         "class": "logging.handlers.SysLogHandler",
          "formatter": "syslog_fmt",
          "address": "/dev/log"
      }
    },
    "root": {
      "handlers": [
        "syslog"
      ]
    }
  }
}
```

syslog 地址可为 Unix 域套接字或 UDP 地址，如：
- `/dev/log`（大多数 Linux）
- `/var/run/syslog`（MacOS）
- `localhost:514`（本地 UDP）
- `<ip>:514`（远程 UDP）

命令行用法（已废弃）：
- `--logfile syslog:/dev/log`
- `--logfile syslog`
- `--logfile syslog:/var/run/syslog`
- `--logfile syslog:localhost:514`
- `--logfile syslog:<ip>:514`

### 日志输出到 journald

需安装 `cysystemd`（`pip install cysystemd`，仅 Linux）。

配置示例：
```json
{
  // ...
  "log_config": {
    "version": 1,
    "formatters": {
      "journald_fmt": {
        "format": "%(name)s - %(levelname)s - %(message)s"
      }
    },
    "handlers": {
      "journald": {
         "class": "cysystemd.journal.JournaldLogHandler",
          "formatter": "journald_fmt"
      }
    },
    "root": {
      "handlers": [
        "journald"
      ]
    }
  }
}
```

日志可用 `journalctl -f` 或 `journalctl -f -u freqtrade.service` 查看。

命令行用法（已废弃）：
- `--logfile journald`
