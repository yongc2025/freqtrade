# 安装指南

本页解释了如何为运行机器人准备环境。

Freqtrade 文档描述了多种安装 Freqtrade 的方法：

* [Docker 镜像](Docker快速入门.md)（独立页面）
* [脚本安装](#脚本安装)
* [手动安装](#手动安装)
* [使用 Conda 安装](#使用-conda-安装)

请考虑使用预构建的 [Docker 镜像](Docker快速入门.md)以快速开始。

!!! Note "更新"
    保持 Freqtrade 更新对于[确保与交易所 API 的持续兼容性](更新指南.md#为什么要更新)非常重要。
    请参阅[更新指南](更新指南.md)了解如何更新安装的详细信息。

!!! Note "Windows 用户"
    我们**强烈**建议 Windows 用户使用 [Docker](Docker快速入门.md)，因为这将工作得更轻松、更顺畅（也更安全）。

    如果无法执行此操作，请尝试使用 Windows Linux 子系统 (WSL) —— Ubuntu/Linux 指说明对其适用。
    如果您确实想在 Windows 上原生安装 Freqtrade，最好使用 [`./setup.ps1` 安装脚本](#使用-setupps1-windows)。

    此外，请确保使用 64 位版本的 Python，因为 32 位版本有严重的内存限制，这可能会对您的回测/超参数优化体验产生负面影响。

## 信息

安装和运行 Freqtrade 最简单的方法是克隆机器人的 Github 仓库，然后运行 `./setup.sh`（Windows 为 `./setup.ps1`）脚本（如果该脚本适用于您的平台）。

!!! Note "版本注意事项"
    克隆仓库时，默认工作分支的名称为 `develop`。该分支包含所有最新功能（由于自动化测试，可以认为相对稳定）。
    `stable` 分支包含上一个版本的代码（通常每月更新一次，基于约一周前 `develop` 分支的快照，以防止打包错误，因此可能更稳定）。

!!! Note
    假设已安装 [uv](https://docs.astral.sh/uv/)，或者安装了 Python 3.11 或更高版本以及相应的 `pip`。如果情况并非如此，安装脚本将发出警告并停止。克隆 Freqtrade 仓库还需要安装 `git`。
    此外，必须安装 Python 头文件（`python<版本号>-dev` / `python<版本号>-devel`）才能成功完成安装。

!!! Warning "准确的时钟"
    运行机器人的系统时钟必须准确，且应足够频繁地与 NTP 服务器同步，以避免与交易所通信时出现问题。

## 系统要求

这些要求同时适用于[脚本安装](#脚本安装)和[手动安装](#手动安装)。

!!! Note "ARM64 系统"
    如果您运行的是 ARM64 系统（如 MacOS M1 或 Oracle VM），请使用 [Docker](Docker快速入门.md) 运行 Freqtrade。
    虽然可以通过一些手动操作进行原生安装，但目前尚不支持。

### 安装指南

* [Python >= 3.11](http://docs.python-guide.org/en/latest/starting/installation/)
* [pip](https://pip.pypa.io/en/stable/installing/)
* [git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)
* [virtualenv](https://virtualenv.pypa.io/en/stable/installation.html) (推荐)

### 安装代码

我们包含/收集了适用于 Ubuntu、MacOS 和 Windows 的安装说明。这些是指导方针，您在其他发行版上的成功程度可能会有所不同。
首先列出 OS 特定步骤，下方的公共部分对所有系统都是必需的。

!!! Note
    假设 Python 3.11 或更高版本以及相应的 pip 可用。

=== "Debian/Ubuntu"
    #### 安装必要的依赖项

    ```bash
    # 更新仓库
    sudo apt-get update

    # 安装软件包
    sudo apt install -y python3-pip python3-venv python3-dev python3-pandas git curl
    ```

=== "MacOS"
    #### 安装必要的依赖项

    如果您还没有安装 [Homebrew](https://brew.sh/)，请先安装。

    ```bash
    # 安装软件包
    brew install gettext libomp
    ```
    !!! Note
        假设您的系统中安装了 brew，`setup.sh` 脚本将为您安装这些依赖项。

=== "RaspberryPi/Raspbian"
    以下内容假设使用的是最新的 [Raspbian Buster lite 镜像](https://www.raspberrypi.org/downloads/raspbian/)。
    此镜像预装了 Python 3.11，可以轻松启动并运行 Freqtrade。

    已在运行 Raspbian Buster lite 镜像并应用了所有更新的 Raspberry Pi 3 上进行测试。

    ```bash
    sudo apt-get install python3-venv libatlas-base-dev cmake curl libffi-dev
    # 使用 piwheels.org 加速安装
    sudo echo "[global]\nextra-index-url=https://www.piwheels.org/simple" > tee /etc/pip.conf

    git clone https://github.com/freqtrade/freqtrade.git
    cd freqtrade

    bash setup.sh -i
    ```

    !!! Note "安装时长"
        取决于您的网速和树莓派版本，安装可能需要数小时才能完成。
        因此，我们建议按照 [Docker 快速入门文档](Docker快速入门.md)通过预构建的树莓派 Docker 镜像进行安装。

    !!! Note
        上述操作不会安装超参数优化 (Hyperopt) 的依赖项。要安装这些依赖，请使用 `python3 -m pip install -e .[hyperopt]`。
        我们不建议在树莓派上运行超参数优化，因为这是一项非常耗资源的操作，应该在性能强大的机器上完成。

## Freqtrade 代码库

Freqtrade 是一个开源加密货币交易机器人，其代码托管在 `github.com`。

```bash
# 下载 freqtrade 代码库的 `develop` 分支
git clone https://github.com/freqtrade/freqtrade.git

# 进入下载后的目录
cd freqtrade

# 您的选择 (1): 新手用户
git checkout stable

# 您的选择 (2): 高级用户
git checkout develop
```

(1) 此命令将克隆的仓库切换到 `stable` 分支。如果您希望保持在 (2) `develop` 分支，则不需要此操作。

您可以稍后随时使用 `git checkout stable` / `git checkout develop` 命令在分支之间切换。

??? Note "从 pypi 安装"
    安装 Freqtrade 的另一种方法是从 [pypi](https://pypi.org/project/freqtrade/) 安装。缺点是此方法要求预先正确安装 ta-lib，因此目前不是推荐的安装方法。

    ``` bash
    pip install freqtrade
    ```

## 脚本安装

安装 Freqtrade 的第一种方法是使用提供的 Linux/MacOS `./setup.sh` 脚本，该脚本将安装所有依赖项并帮助您配置机器人。

确保您满足[系统要求](#系统要求)并已下载 [Freqtrade 代码库](#freqtrade-代码库)。

### 使用 /setup.sh -install (Linux/MacOS)

如果您使用的是 Debian、Ubuntu 或 MacOS，Freqtrade 提供了安装脚本。

```bash
# --install, 从头开始安装 freqtrade
./setup.sh -i
```

#### /setup.sh 脚本的其他选项

您还可以使用 `./setup.sh` 来更新、配置和重置机器人的代码库。

```bash
# --update, 执行 git pull 以进行更新。
./setup.sh -u
# --reset, 强行重置您的 develop/stable 分支。
./setup.sh -r
```

```
** --install **

使用此选项，脚本将安装机器人及大多数依赖项：
您需要预先安装好 git 和 python 3.11+ 才能使此操作生效。

* 必要软件如：`ta-lib`
* 在 `.venv/` 下设置您的虚拟环境

此选项是安装任务和 `--reset` 的组合。

** --update **

此选项将拉取当前分支的最新版本并更新您的虚拟环境。定期运行带有此选项的脚本以更新机器人。

** --reset **

此选项将强行重置您的分支（仅当您处于 `stable` 或 `develop` 分支时）并重新创建虚拟环境。
```

#### 激活您的虚拟环境

每次打开新终端时，都必须运行 `source .venv/bin/activate` 以激活您的虚拟环境。

```bash
# 激活虚拟环境
source ./.venv/bin/activate
```

### 使用 ./setup.ps1 (Windows)

该脚本会询问您几个问题，以确定应安装哪些部分。

```powershell
Set-ExecutionPolicy -ExecutionPolicy Bypass
cd freqtrade
. .\setup.ps1
```

#### 激活您的虚拟环境 (Windows)

```powershell
# 激活虚拟环境
. .\.venv\Scripts\Activate.ps1
```

[您现在已准备好](#您已准备好)运行机器人。

## 手动安装

确保您满足[系统要求](#系统要求)并已下载 [Freqtrade 代码库](#freqtrade-代码库)。

### 设置 Python 虚拟环境 (virtualenv)

您将在隔离的 `虚拟环境 (virtual environment)` 中运行 Freqtrade。

```bash
# 在目录 /freqtrade/.venv 中创建虚拟环境
python3 -m venv .venv

# 运行虚拟环境
source .venv/bin/activate
```

### 安装 Python 依赖项

```bash
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
# 安装 freqtrade
python3 -m pip install -e .
```

[您现在已准备好](#您已准备好)运行机器人。

### (可选) 安装后任务

!!! Note 
    如果您要在服务器上运行机器人，应考虑使用 [Docker](Docker快速入门.md) 或终端复用器，如 `screen` 或 [`tmux`](https://zh.wikipedia.org/wiki/Tmux)，以避免机器人在注销时停止。

在带有 `systemd` 软件套件的 Linux 上，作为可选的安装后任务，您可能希望将机器人设置为 `systemd 服务` 运行，或将其配置为向 `syslog` / `rsyslog` 或 `journald` 守护进程发送日志消息。有关详细信息，请参阅[高级日志](高级安装配置.md#高级日志)。

## 使用 Conda 安装

也可以使用 Miniconda 或 Anaconda 安装 Freqtrade。我们推荐使用 Miniconda，因为其安装占用空间更小。Conda 将自动准备并管理 Freqtrade 程序的各种库依赖关系。

### 什么是 Conda？

Conda 是适用于多种编程语言的软件包、依赖项和环境管理器：[Conda 文档](https://docs.conda.io/projects/conda/en/latest/index.html)

### 使用 Conda 安装

#### 安装 Conda

[在 Linux 上安装](https://conda.io/projects/conda/en/latest/user-guide/install/linux.html#install-linux-silent)

[在 Windows 上安装](https://conda.io/projects/conda/en/latest/user-guide/install/windows.html)

回答所有问题。安装完成后，必须关闭终端并重新开启。

#### 下载 Freqtrade

下载并安装 Freqtrade。

```bash
# 下载 freqtrade
git clone https://github.com/freqtrade/freqtrade.git

# 进入下载的目录 'freqtrade'
cd freqtrade      
```

#### 安装 Freqtrade：Conda 环境

```bash
conda create --name freqtrade python=3.12
```

!!! Note "创建 Conda 环境"
    conda 命令 `create -n` 会自动为选定的库安装所有嵌套依赖项，安装命令的一般结构为：

    ```bash
    # 选择您自己的软件包
    conda env create -n [环境名称] [python 版本] [软件包]
    ```

#### 进入/退出 Freqtrade 环境

要检查可用的环境，请输入

```bash
conda env list
```

进入已安装的环境

```bash
# 进入 conda 环境
conda activate freqtrade

# 退出 conda 环境 - 现在不要执行此操作
conda deactivate
```

使用 pip 安装最后的 Python 依赖项

```bash
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
python3 -m pip install -e .
```

[您现在已准备好](#您已准备好)运行机器人。

### 重要快捷方式

```bash
# 列出已安装的 conda 环境
conda env list

# 激活基础环境
conda activate

# 激活 freqtrade 环境
conda activate freqtrade

# 停用任何 conda 环境
conda deactivate                              
```

### 关于 Anaconda 的更多信息

!!! Info "大型新软件包"
    有时，在创建时填充了选定软件包的新 Conda 环境可能比在先前设置的环境中安装大型、沉重的库或应用程序花费的时间更短。

!!! Warning "在 conda 中使用 pip 安装"
    Conda 的文档指出，在 Conda 中不应使用 pip，因为可能会发生内部问题。
    但是，这种情况很少见。[Anaconda 博客文章](https://www.anaconda.com/blog/using-pip-in-a-conda-environment)

    尽管如此，这就是为什么首选 `conda-forge` 频道的原因：

    * 提供更多的库（对 `pip` 的需求更少）
    * `conda-forge` 与 `pip` 配合得更好
    * 库更新

祝交易愉快！

## 故障排除

### 常见问题："command not found"

如果您使用了 (1) `脚本` 或 (2) `手动` 安装，则需要在虚拟环境中运行机器人。如果您遇到如下报错，请确保 venv 已激活。

```bash
# 如果：
bash: freqtrade: command not found

# 那么激活您的虚拟环境：
source ./.venv/bin/activate
```

### MacOS 安装错误

在较新版本的 MacOS 上，安装可能会失败并显示诸如 `error: command 'g++' failed with exit status 1` 之类的错误。

此错误需要显式安装 SDK 头文件，这些头文件在 MacOS 的此版本中默认不安装。
对于 MacOS 10.14，可以使用以下命令完成。

```bash
open /Library/Developer/CommandLineTools/Packages/macOS_SDK_headers_for_macOS_10.14.pkg
```

如果此文件不存在，那么您可能使用的是不同版本的 MacOS，因此您可能需要咨询互联网了解具体的解决方法详情。

### Windows 安装错误

```bash
error: Microsoft Visual C++ 14.0 is required. Get it with "Microsoft Visual C++ Build Tools": http://landinghub.visualstudio.com/visual-cpp-build-tools
```

遗憾的是，许多需要编译的软件包不提供预构建的 wheel。因此，必须安装 C/C++ 编译器并使其可用于 Python 环境。

您可以从 [Visual Studio 网站](https://visualstudio.microsoft.com/visual-cpp-build-tools/)下载 Visual C++ 生成工具，并以默认配置安装其中的“使用 C++ 的桌面开发”。遗憾的是，这是一个沉重的下载内容/依赖项，因此您可能想先考虑使用 WSL2 或 [Docker Compose](Docker快速入门.md)。
